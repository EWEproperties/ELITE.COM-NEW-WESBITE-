# Elite World Estates – new website (English)

Static rebuild of the eliteworldestates.com home page. Open `index.html` in a browser; no build step.

- `index.html` – page structure and copy
- `css/style.css` – styling (colours and fonts at the top)
- `js/properties.js` – the property listings shown on the home page
- `js/main.js` – renders the listing cards and the mobile menu
